# Firebase Email Verification Setup

## Problem
Firebase's `sendEmailVerification()` only works if you configure it in Firebase Console. Without setup, emails don't send.

## Solution: Enable Email Verification in Firebase Console

### Step 1: Go to Firebase Console

1. Open [console.firebase.google.com](https://console.firebase.google.com)
2. Select project: **violess-4e542**
3. Go to **Authentication** (left sidebar)

### Step 2: Enable Email Provider

1. Click **Sign-in method** tab
2. Look for **Email/Password**
3. If it says "Disabled", click to enable it
4. Toggle **Email/Password** ON
5. Make sure **Email link (passwordless sign-in)** is OFF
6. Click **Save**

### Step 3: Set Up Email Templates

1. Still in **Authentication** → **Sign-in method**
2. Scroll down to **Email Templates** section
3. You should see these templates:
   - Email Verification
   - Password Reset
   - Email Change
   - SMS

4. Click on **Email Verification**
5. A popup will open showing the template
6. This is the email users will receive when you call `sendEmailVerification()`

### Step 4: Customize Email (Optional)

In the Email Verification template:
- **Subject**: Keep or customize (e.g., "Verify Your Vio-less Account")
- **Body**: You can add custom text, logo, etc.
- The verification link will be auto-generated by Firebase

Common template:
```
Hello,

Please verify your email address by clicking the link below:

%LINK%

This link expires in 24 hours.

Thank you,
Vio-less Team
```

Click **Save** when done.

## Test It

After setting up:

1. Rebuild mobile app
2. Try creating account
3. Should see "Verification email sent!" message
4. Check your email inbox for verification email
5. Click the link to verify

## Troubleshooting

### Email Still Not Arriving

**Check 1: Email Provider Enabled**
- Go to **Authentication** → **Sign-in method**
- Verify **Email/Password** shows a checkmark ✓

**Check 2: Template Exists**
- Go to **Email Templates**
- Click **Email Verification**
- Should show a template, not "No template"

**Check 3: Check Spam Folder**
- Verification email might go to spam
- Add to contacts to fix

**Check 3: Try Different Email**
- Test with personal email first (not test@example.com)
- Gmail/Outlook are more reliable

### "Network request failed" Error

If you see this error:
1. Backend is not the issue - it's Firebase
2. Mobile app can't reach Firebase
3. Rebuild mobile app from scratch
4. Make sure Firebase config is correct in `/mobile/src/config/firebase.js`

## Firebase Config Check

Verify `/mobile/src/config/firebase.js` has your config:

```javascript
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",

  projectId: "violess-4e542",
  storageBucket: "violess-4e542.appspot.com",
  messagingSenderId: "...",
  appId: "...",

```

All fields must be filled in correctly.
